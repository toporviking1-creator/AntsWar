# Суперколония

Мобильная RTS про окопную войну двух колоний муравьёв: красные против чёрных.

- 2 колонии, у каждой 4 касты и свой спецприём (Ярость / Панцирь)
- Кампания из 8 фронтов за каждую сторону
- Управление: рамка пальцем — выделить, тап по земле — марш, тап по врагу — атака

Один файл `index.html`, без зависимостей. Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
