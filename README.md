# Суперколония

Мобильная RTS про окопную войну колоний муравьёв: красные, чёрные и жёлтые.

- 3 колонии, у каждой 4 касты и свой спецприём (Ярость / Панцирь / Рывок)
- Все кампании и фронты открыты сразу — можно начинать с любой
- Тренировочная кампания: 8 фронтов за каждую сторону
- Кампания 2 «Туман войны» (открывается после тренировочной): обзор по кастам, враг тоже в тумане, гнездо врага каждый раз в новом месте, засады
- С 3-го фронта в обеих кампаниях с краёв карты выползают случайные жуки-монстры (жужелица, носорог, бомбардир, олень). Нападают на всех; кто добил — получает подкрепления
- Кампания 3 «Захват» (после «Тумана войны»): кормушки дают +15% к выводу и место под доп. гнездо, ночь режет обзор, ливни затапливают низины, медведки и черви вылезают из-под земли и жрут всех в круге
- Кампания 4 «Боссы и кочевники» (после «Захвата»): стражи у вражеских гнёзд (муравьиный лев, богомол, паук-крестовик, сороконожка) — пока страж жив, гнездо неуязвимо; лавины кочевых муравьёв жрут всех без перемирия
- Кампания 5 «Сектора» (после «Боссов», как в Z): 6→14 секторов на фронт, каждый даёт всей колонии своё преимущество, пока удерживаешь — 🦷 укус, ☠️ яд, 🦵 скорость, 🛡️ броня, 👁️ обзор, 🥚 вывод, 💧 лечение, 🎯 дальность стрелков, ⚡ спецприём, 🧱 прочность гнёзд, 💢 скорость атаки. Одинаковые складываются, враг тоже захватывает; верхние сектора на старте у врага. Победа — только через гнездо. Туман, жуки, ночь, ливни, медведки
- Кампания 6 «Три колонии»: три колонии каждая сама за себя на карте секторов. Новые сектора — 👑 Тронный зал (двойной вес), 🪲 Жучиный феромон (жуки не трогают), 🦴 Падальщики (тела кормят на 60% лучше). Господство: удержи сектора на 60% веса 60 секунд — победа (враг тоже так может). Если вырвешься вперёд — враги заключают союз против тебя. На каждом фронте ещё и дикая колония 🐜 Аргентинских (за них играть нельзя): Мураши вылупляются роем по 3–4, Бочонки — медленные танки
- Кампания 7 «Оборона» 🛡️: вражеского гнезда нет — 6→12 волн с краёв карты и сверху (касты → жуки → кочевники → боссы, в финале сороконожка). Перед волной — отсчёт, направление и состав. Ловушки быстрее на 30% и по 2 заряда, сектора у гнезда можно отбить, кнопка «Волна!» вызывает следующую волну досрочно
- 📅 Испытание дня: у всех в один день одинаковое испытание (сид — дата по Москве). Колонии, карта и 2–3 модификатора (туман, ночь, ливни, медведки, страж, кочевники, сектора, третья колония, оборона) плюс «злые» (враг +25%, без ловушек, только 2 касты). Сложность растёт с понедельника к воскресенью. Рекорд дня, серия побед, история за 7 дней, кнопка «Скопировать результат»
- Ловушки игрока (🪤): смола, ядовитое облако, ложный след. Природные ловушки: роса, росянка, шипы акации
- Лечение у своих гнёзд и кормушек; лёгкие касты таскают тела в гнездо — это ускоряет вывод
- Синтезированный звук (кнопка 🔊)
- Лёгкие касты (Разведчик, Ополченец) уворачиваются от снарядов и охотятся на стрелков; ИИ отвечает на массу стрелков быстрыми юнитами
- Управление: рамка пальцем — выделить, тап по земле — марш, тап по врагу — атака

Один файл `index.html`, без зависимостей. Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
