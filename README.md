# Суперколония

Мобильная RTS про окопную войну двух колоний муравьёв: красные против чёрных.

- 2 колонии, у каждой 4 касты и свой спецприём (Ярость / Панцирь)
- Тренировочная кампания: 8 фронтов за каждую сторону
- Кампания 2 «Туман войны» (открывается после тренировочной): обзор по кастам, враг тоже в тумане, гнездо врага каждый раз в новом месте, засады
- С 3-го фронта в обеих кампаниях с краёв карты выползают случайные жуки-монстры (жужелица, носорог, бомбардир, олень). Нападают на всех; кто добил — получает подкрепления
- Кампания 3 «Захват» (после «Тумана войны»): кормушки дают +15% к выводу и место под доп. гнездо, ночь режет обзор, ливни затапливают низины, медведки и черви вылезают из-под земли и жрут всех в круге
- Лёгкие касты (Разведчик, Ополченец) уворачиваются от снарядов и охотятся на стрелков; ИИ отвечает на массу стрелков быстрыми юнитами
- Управление: рамка пальцем — выделить, тап по земле — марш, тап по врагу — атака

Один файл `index.html`, без зависимостей. Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
